Northern Scientific — Invoicing Tool

Zack's playbook · turn the login sheet + COCs into validated QuickBooks invoices, in minutes

What this tool does. It reads your Login sheet, prices every sample from the Customer Pricing sheet, groups them into one invoice per COC, flags anything it isn't sure about, and hands you a QuickBooks import file. It replaces the manual login-sheet → pricing → tracker cross-referencing. Everything runs in your browser — nothing you load leaves your PC.

1One-time setup ~10 min, do once

A. Open the portal  ·  B. Connect OneDrive so you never upload files manually.

A · Open & bookmark the portal

  1. In Edge or Chrome, go to [ PORTAL LINK — Chris will send ] and bookmark it.
  2. If a sign-in is shown, log in with the details Chris sends you: User: [ username ]   Password: [ sent separately ].

B · Connect your OneDrive folder (so files sync automatically)

  1. In SharePoint, open the Invoicing document library (the one with the Login sheet, Pricing sheet, and the monthly COC folders).
  2. Click Sync in the top toolbar and allow OneDrive to open. The Invoicing folder now appears in File Explorer → OneDrive → …Invoicing and updates itself whenever SharePoint changes.
  3. Back in the portal, click “Connect OneDrive folder”, pick that Invoicing folder, and click Allow. You only do this once — the portal remembers it.
Why this matters: once connected, you never download or upload anything. The tool reads whatever SharePoint has synced down. (Manual drag-and-drop is still there as a backup for any week.)

2Your weekly run ~10 min

  1. Make sure the week's COCs are filed in the Invoicing folder and the Login sheet is up to date (they sync to OneDrive automatically).
  2. Open the portal → click “Refresh from OneDrive.”  (Or drag the files in manually — backup method.)
  3. The tool prices every sample, builds one invoice per COC, and shows two lists: Auto-priced ✅ and Needs review ⚠.
  4. Work through the Needs review list (see §3). Usually a handful of items.
  5. Click Download QuickBooks file (and Download tracker for your records).
  6. In QuickBooks Online: Settings ⚙ → Import data → Invoices → upload the file → map columns → Import.

3Clearing “Needs review”

The tool never guesses silently — if it isn't sure, it flags it for you. What each flag means:

FlagWhat it means / what to do
no price / new clientThat client or test isn't in the Pricing sheet. Add their row/price to the Pricing sheet, then Refresh.
price differsThe tool's sheet-based price differs from an old manual amount. The Pricing sheet wins — confirm and move on.
package uncertaine.g. a concentrate ordered without terps. Check the price; if a “without-terps” rate is needed, add it to the Pricing sheet note.
no COCA logged sample has no matching COC file — confirm it was submitted/scanned. Retests (-2 / -3) are expected to have no COC and won't be flagged.

4What you maintain — and what you don't

  • ✍ Keep current — the Pricing sheet. Add a row for any brand-new client, and update prices and the package “includes / without” notes when they change. The tool is only as accurate as this sheet.
  • ✅ Leave alone — the Login sheet. Keep logging samples exactly as you do now. The tool reads it as-is — it handles messy client-name spellings and figures out COCs from the file names. No clean-up needed.
  • 🗑 Stop doing by hand — the invoice tracker. The tool generates the updated tracker for you.

5Rules to remember

  • The Pricing sheet is the bible. If a number looks wrong, fix the sheet, not the invoice, then Refresh.
  • Rush (set in the TAT column, e.g. Rush C, Rush All) adds +50% of the rushed test's price.
  • Retests (sample IDs ending -2 / -3) have no COC — that's normal.
  • Invoices = one per COC. Samples are billed on submission.
  • Privacy: everything runs in your browser; no client data is uploaded anywhere.

6If something goes wrong

  • Portal won't load / looks blank: refresh the page; use Edge or Chrome (not Internet Explorer).
  • “Refresh from OneDrive” is greyed out: reconnect the folder (§1-B).
  • A client shows “unresolved”: their name is brand-new — add them to the Pricing sheet.
  • Anything else: message Chris.
